# 呼叫前原始碼檢視

[简体中文](README_PRE_CALL_SOURCE_VIEWS.md) · **繁體中文** · [日本語](README_PRE_CALL_SOURCE_VIEWS.ja.md) · [English](README_PRE_CALL_SOURCE_VIEWS.en.md)

[`pre_call_source_views.py`](pre_call_source_views.py) 將已準備的 helper 來源與實際 Python 程式碼物件對應，儲存同一呼叫所需的完整函式形狀、入口繫結和現場身份。執行回撥以已經準備好的檢視識別實際呼叫前位置。

[原呼叫目錄](README_PRE_CALL_CAPTURE_CATALOG.zh-TW.md)提供父呼叫與入口引用；[呼叫前觀察器](README_M68K_PRE_CALL_CAPTURE.zh-TW.md)讀取呼叫位置的真實狀態。
