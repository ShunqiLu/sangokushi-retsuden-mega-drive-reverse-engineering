# リズムチャンネルの Z80 WZ 状態

[简体中文](README_RHYTHM_WZ.md) · [繁體中文](README_RHYTHM_WZ.zh-TW.md) · **日本語** · [English](README_RHYTHM_WZ.en.md)

Z80 の `BIT 2,(HL)` は内部状態 WZ を使って未文書化のフラグを設定します。リズム処理は [`rhythm_wz.py`](rhythm_wz.py) で同じ Z80 状態に該当アドレスを作る処理をたどり、その状態を実際のビット判定に渡します。音声処理は元のポート、レジスター、デバイス入力で状態を維持します。

WZ は確認済みの元の処理で更新します。初期状態は出所を観測できる実行環境から取得します。チャンネルイベント、タイマー、IRQ はサウンドドライバーとデバイスプロバイダーが進めます。
