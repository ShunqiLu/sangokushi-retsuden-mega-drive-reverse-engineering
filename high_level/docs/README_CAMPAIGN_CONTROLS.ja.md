# 新規ゲームの設定操作

[简体中文](README_CAMPAIGN_CONTROLS.md) · [繁體中文](README_CAMPAIGN_CONTROLS.zh-TW.md) · **日本語** · [English](README_CAMPAIGN_CONTROLS.en.md)

コントローラーはボタンを押した瞬間を検出します。ホスト側のキーボード割り当ては実行設定で定義します。

| ボタン | 新規ゲームの設定 |
| --- | --- |
| 上／下 | 年代、難易度、アニメーション、表示速度の候補を循環します。 |
| 左／右 | 現在の欄で君主候補を循環します。 |
| C | 現在の欄を確定して次へ進みます。最終確認欄では設定の終了を要求します。 |
| B | 前の欄へ戻ります。最終確認欄では先頭に戻り、設定の説明を表示します。 |
| Start | 現在の欄から設定の終了を要求します。 |
| A | この画面の設定を維持します。 |

| フィールド番号 | 設定 | 範囲 |
| --- | --- | --- |
| 0 | 年代 | 0–2 |
| 1 | 難易度 | 0–2 |
| 2 | アニメーション | 0–1 |
| 3 | 表示速度 | 0–2 |
| 4 | 第 1 プレイヤーの君主 | 年代 0 と 1 は各 7 名、年代 2 は 3 名から選べます。 |
| 5／6 | 第 2・第 3 プレイヤーの君主 | 選択済みの君主を除外し、参加人数に応じて表示します。 |
| `5 + 7034` | 最終確認 | `7034` の 0、1、2 はそれぞれ 1 人、2 人、3 人を表します。 |

最初の 4 項目と第 1 プレイヤーの君主はコントローラー 1、第 2・第 3 プレイヤーの君主はコントローラー 2 の状態 `F605` を使います。対応するカウンター `7038` と `703A` がそれぞれ 16 に達すると、追加の君主欄で入力を受け付けます。

終了要求で `703E` を設定します。IRQ がフェードアウトカウンター `7042` を 16 まで進めると呼び出し元へ戻ります。`0x03076E` は `7024/7026/7028/702A` と君主の選択をゲーム状態に反映します。[コントローラー待ち](README_CONTROLLER_MENU_STEPS.ja.md)と[新規ゲームの初期化](README_CAMPAIGN_MENU_STEPS.ja.md)も参照してください。
