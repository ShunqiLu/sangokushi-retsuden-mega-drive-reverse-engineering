# 新局设置页操作

**简体中文** · [繁體中文](README_CAMPAIGN_CONTROLS.zh-TW.md) · [日本語](README_CAMPAIGN_CONTROLS.ja.md) · [English](README_CAMPAIGN_CONTROLS.en.md)

实体手柄按键按新按下边沿识别。宿主的键盘对应关系由运行配置定义。

| 按键 | 新局设置 |
| --- | --- |
| 上／下 | 在年代、难度、动画和显示速度字段内循环选择。 |
| 左／右 | 在当前君主字段内循环选择。 |
| C | 确认当前字段并移至下一项。整页确认位置上的 C 请求结束设置。 |
| B | 返回上一项；在整页确认位置回到首项并显示设置说明。 |
| Start | 在当前字段请求结束设置。 |
| A | 在此页保持当前设置。 |

| 字段索引 | 内容 | 范围 |
| --- | --- | --- |
| 0 | 年代 | 0–2 |
| 1 | 难度 | 0–2 |
| 2 | 动画 | 0–1 |
| 3 | 显示速度 | 0–2 |
| 4 | 第一位玩家君主 | 年代 0、1 各有七名候选；年代 2 有三名候选。 |
| 5／6 | 第二／第三位玩家君主 | 避让已选君主，并按参与人数显示。 |
| `5 + 7034` | 整页确认 | `7034` 的 0、1、2 分别对应一、二、三位玩家。 |

前四项与第一位君主由第一手柄控制；第二、第三位君主使用第二手柄状态 `F605`。控制计数 `7038` 与 `703A` 各达到 16 时附加君主字段响应输入。

结束请求设置 `703E`。IRQ 将淡出计数 `7042` 推进到 16 后，设置程序将控制返回给调用者；`0x03076E` 将 `7024/7026/7028/702A` 及君主选择提交到游戏状态。参见[控制器等待](README_CONTROLLER_MENU_STEPS.md)和[新局初始化](README_CAMPAIGN_MENU_STEPS.md)。
