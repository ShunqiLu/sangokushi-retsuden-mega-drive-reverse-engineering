# 新局設定頁操作

[简体中文](README_CAMPAIGN_CONTROLS.md) · **繁體中文** · [日本語](README_CAMPAIGN_CONTROLS.ja.md) · [English](README_CAMPAIGN_CONTROLS.en.md)

實體手柄按鍵按新按下邊沿識別。宿主的鍵盤對應關係由執行配置定義。

| 按鍵 | 新局設定 |
| --- | --- |
| 上／下 | 在年代、難度、動畫和顯示速度欄位內迴圈選擇。 |
| 左／右 | 在當前君主欄位內迴圈選擇。 |
| C | 確認當前欄位並移至下一項。整頁確認位置上的 C 請求結束設定。 |
| B | 返回上一項；在整頁確認位置回到首項並顯示設定說明。 |
| Start | 在當前欄位請求結束設定。 |
| A | 在此頁保持當前設定。 |

| 欄位索引 | 內容 | 範圍 |
| --- | --- | --- |
| 0 | 年代 | 0–2 |
| 1 | 難度 | 0–2 |
| 2 | 動畫 | 0–1 |
| 3 | 顯示速度 | 0–2 |
| 4 | 第一位玩家君主 | 年代 0、1 各有七名候選；年代 2 有三名候選。 |
| 5／6 | 第二／第三位玩家君主 | 避讓已選君主，並按參與人數顯示。 |
| `5 + 7034` | 整頁確認 | `7034` 的 0、1、2 分別對應一、二、三位玩家。 |

前四項與第一位君主由第一手柄控制；第二、第三位君主使用第二手柄狀態 `F605`。控制計數 `7038` 與 `703A` 各達到 16 時附加君主欄位響應輸入。

結束請求設定 `703E`。IRQ 將淡出計數 `7042` 推進到 16 後，設定程式將控制返回給呼叫者；`0x03076E` 將 `7024/7026/7028/702A` 及君主選擇提交到遊戲狀態。參見[控制器等待](README_CONTROLLER_MENU_STEPS.zh-TW.md)和[新局初始化](README_CAMPAIGN_MENU_STEPS.zh-TW.md)。
