# 原版相容行為

[简体中文](ORIGINAL_GAME_BUGS.md) · **繁體中文** · [日本語](ORIGINAL_GAME_BUGS.ja.md) · [English](ORIGINAL_GAME_BUGS.en.md)

下表記錄卡匣遊戲中可區分的行為與邊界。復原邏輯沿用這些行為，包括計數迴繞、表項殘值、指標覆蓋和部分寫入。編號用於定位同一現象。

| 編號 | 原版行為 |
| --- | --- |
| BUG-001 | 糧食運輸累加溢位後降為 99,999。 |
| BUG-002 | 到達城市的一條鄰接匹配分支受恆假條件限制。 |
| BUG-003 | 鄰接候選刪除使用較短的壓縮複製範圍。 |
| BUG-004 | AI 尋路呼叫覆蓋了後續選擇仍使用的城市表指標。 |
| BUG-005 | 鄰接費用的兩次讀取均使用網格索引。 |
| BUG-006 | 到達隊伍的首領搜尋止於倒數第二槽；移除時跳過首項搬移。 |
| BUG-007 | 清理勢力名單時使用已自增的源指標，可能擦掉未讀終止符。 |
| BUG-008 | AI 購武器只讀 BYTE 卻比較 WORD，殘留高位元組使購買被跳過。 |
| BUG-009 | AI 武器購買以首個武將槽作為寫入目標。 |
| BUG-010 | AI 開發預算丟棄隨機比例，實際使用四倍城市編號。 |
| BUG-011 | 訓練觸頂修正使進度增量反而超過原始增量。 |
| BUG-012 | AI 招兵容量門比較名單遊標相對記憶體，而非兵力表。 |
| BUG-013 | AI 第三個玩家歸屬檢查比較先前選中城市而非當前歸屬方。 |
| BUG-014 | 尋路前沿耗盡後仍沿用搜尋分支。 |
| BUG-015 | AI 城市鄰接候選表包含兩條單向關係。 |
| BUG-016 | 軍隊資源決策的最終動作是 13；其中一路在同一呼叫中也寫入 12。 |
| BUG-017 | 兩處隨機分支測試恆為零，隨機種子副作用仍執行。 |
| BUG-018 | 最大敵軍候選以無符號最大值作為比較基準。 |
| BUG-019 | 名單強度累計量的低 WORD 被每個成員號和終止符覆蓋。 |
| BUG-020 | 城市強度掃描讀取目標城市後，又將它覆蓋為武將計數器。 |
| BUG-021 | 軍隊購裝備準備了裝備表指標，卻寫入屬性表。 |
| BUG-022 | 城市關聯武將缺失時，分支迴圈停在原地址。 |
| BUG-023 | 經濟支援城市掃描的子函式改變了後續“已處理”檢查基址。 |
| BUG-024 | 支援名單的追加寫在舊終止符之後。 |
| BUG-025 | 軍隊名單排序沿用已經減到 FFFF 的計數作 WORD 地址。 |
| BUG-026 | 補糧價格的非零 LONG 在 WORD 除數口變成零。 |
| BUG-027 | 雙武將行軍費用直接以平均速度作除數，零值到達除法。 |
| BUG-028 | 特殊戰場尾組選值前，八次迴圈始終清同一個槽位。 |
| BUG-029 | 戰場候選去重掃描可越過候選區進入相鄰輸出。 |
| BUG-030 | 戰場預算計算完商之後，重新讀回舊預算。 |
| BUG-031 | 地形篩選準備座標表指標，卻從地圖基址讀座標。 |
| BUG-032 | 一種戰場預算公式混入完整更新後的隨機狀態。 |
| BUG-033 | 武將編號乘四用於座標後，縮放值被寫回名單。 |
| BUG-034 | 兩條名單重排路徑向前複製到相鄰重疊區。 |
| BUG-035 | 名單訓練直接以選中人數作除數，零值到達除法。 |
| BUG-036 | 精靈水平翻轉讀取尺寸後，座標修正恆為 8。 |
| BUG-037 | 戰場強度比的第二側分母重複乘 B400 屬性因子。 |
| BUG-038 | 固定欄位存檔編碼器將非零殘餘位元組寫回輸入遊標。 |
| BUG-039 | 第一類月度事件重複執行六月分支。 |
| BUG-040 | 戰後第二項城市資源的合計寫回戰場暫存表。 |
| BUG-041 | 空軍隊包的平均速度計算耗盡 WORD 計數，零值到達除法。 |
| BUG-042 | 場景人數調整在特定總量下於 15 和 16 間往復。 |
| BUG-043 | 物件行動擴充套件縱向探測的第三個偏移為 3。 |
| BUG-044 | 調色變換入口收到大於 15 的低 WORD 時自鎖。 |
| BUG-045 | 第二側人數調整同樣可能於 15 和 16 間往復。 |
| BUG-046 | 物件追逐分支的比較標誌被中間 MOVE 覆蓋。 |
| BUG-047 | 高位忠誠度彙總從忠誠表取 BYTE，再將其用作當前包偏移。 |
| BUG-048 | 高位忠誠度彙總直接以計數作除數，零值到達除法。 |
| BUG-049 | 行動預算直接以武將 C400 屬性 BYTE 作除數，零值到達除法。 |

與程式碼對應的入口可從[原地址索引](../PENDING_SOURCE_INDEX.zh-TW.md)和[遊戲內容編輯入口](../EDITING.zh-TW.md)查詢。
