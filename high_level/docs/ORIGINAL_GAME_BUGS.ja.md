# 原作の挙動

[简体中文](ORIGINAL_GAME_BUGS.md) · [繁體中文](ORIGINAL_GAME_BUGS.zh-TW.md) · **日本語** · [English](ORIGINAL_GAME_BUGS.en.md)

カウンターの周回、テーブルの残値、ポインターの上書き、部分書き込みなど、再構築版で維持している原作の挙動と境界条件を示します。ID は両版で共通です。

| ID | 原作の挙動 |
| --- | --- |
| BUG-001 | 輸送した兵糧の合計が上限を超えると 99,999 になります。 |
| BUG-002 | 都市の隣接判定の 1 分岐で一致条件が常に偽になります。 |
| BUG-003 | 隣接候補の削除時に、詰め直すコピー範囲が短くなります。 |
| BUG-004 | AI の経路探索が、その後の選択で使う都市表のポインターを上書きします。 |
| BUG-005 | 隣接コストの 2 回の読み出しは、どちらもグリッドインデックスを使います。 |
| BUG-006 | 到着部隊の隊長検索は最後の 1 つ手前のスロットまでです。取り除く際は先頭項目の移動を飛ばします。 |
| BUG-007 | 勢力名簿の整理にインクリメント後のソースポインターを使うため、未読の終端値を消すことがあります。 |
| BUG-008 | AI の武器購入は BYTE を読んで WORD を比較するため、上位バイトの残値で購入を飛ばす場合があります。 |
| BUG-009 | AI の武器購入結果は最初の武将スロットに書き込まれます。 |
| BUG-010 | AI の開発予算は乱数比率を捨てて都市番号の 4 倍を使います。 |
| BUG-011 | 訓練の上限補正によって、進捗が元の増分より大きくなります。 |
| BUG-012 | AI の徴兵上限は兵力表ではなく、名簿カーソルを基準にしたメモリを比較します。 |
| BUG-013 | AI の第 3 プレイヤー所属判定は現在の所属先ではなく、前回選択した都市を比較します。 |
| BUG-014 | 探索前線が空になっても経路探索の分岐を使い続けます。 |
| BUG-015 | AI の都市隣接表には片方向の関係が 2 件あります。 |
| BUG-016 | 軍の資源判断は最終的に行動 13 を書きます。一方の経路では同じ呼び出し中に先に 12 を書きます。 |
| BUG-017 | 2 箇所の乱数分岐判定は常にゼロですが、乱数シードは更新されます。 |
| BUG-018 | 最強敵軍候補の比較基準が符号なし整数の最大値です。 |
| BUG-019 | 各名簿メンバーの番号と終端値が、戦力累計の下位 WORD を上書きします。 |
| BUG-020 | 都市の強度走査は、読み出した対象都市を武将カウンターで上書きします。 |
| BUG-021 | 軍の装備購入では装備表のポインターを用意しますが、属性表に書き込みます。 |
| BUG-022 | 都市に関連する武将が見つからないと、同じアドレスで分岐を繰り返します。 |
| BUG-023 | 経済支援の都市走査で、後続の処理済み判定の基底をサブルーチンが変更します。 |
| BUG-024 | 支援名簿の追記は以前の終端値より後ろに書き込みます。 |
| BUG-025 | 軍の名簿ソートで、使い切ったカウント FFFF を WORD のアドレス計算に使います。 |
| BUG-026 | ゼロでない補給価格の LONG が、WORD の除数に入るとゼロになります。 |
| BUG-027 | 武将 2 名の行軍費用は平均速度をそのまま除数にするため、ゼロも除算に渡ります。 |
| BUG-028 | 特殊戦場の末尾グループを選ぶ前に、8 回のループで同じスロットをクリアします。 |
| BUG-029 | 戦場候補の重複確認が候補領域を越え、隣接する出力領域を読む場合があります。 |
| BUG-030 | 戦場予算は商を計算した後、元の予算を読み直します。 |
| BUG-031 | 地形の絞り込みでは座標表のポインターを用意しますが、座標はマップ基底から読みます。 |
| BUG-032 | 戦場予算の計算式の一つが、更新後の乱数状態全体を使います。 |
| BUG-033 | 座標計算で武将番号を 4 倍した後、その値を名簿に書き戻します。 |
| BUG-034 | 名簿の並べ替えの 2 経路で、隣接して重なる領域へ前方コピーします。 |
| BUG-035 | 名簿の訓練は選択人数を直接除数にするため、ゼロも除算に渡ります。 |
| BUG-036 | スプライトのサイズを読んだ後、左右反転の座標補正が常に 8 になります。 |
| BUG-037 | 戦場の戦力比で、第 2 陣営の分母に B400 の属性係数を重複して掛けます。 |
| BUG-038 | 固定フィールドのセーブエンコーダーは、ゼロでない末尾バイトを入力カーソルの位置に書きます。 |
| BUG-039 | 第 1 種の月例イベントが 6 月分岐を繰り返します。 |
| BUG-040 | 戦後、第 2 の都市資源の合計を戦場バッファーへ書き戻します。 |
| BUG-041 | 空の軍パケットの平均速度計算で WORD カウンターを使い切り、ゼロが除算に渡ります。 |
| BUG-042 | 特定の総量では、シーンの人数調整が 15 と 16 の間を往復します。 |
| BUG-043 | オブジェクト行動の縦方向追加探索では、第 3 のオフセットが 3 です。 |
| BUG-044 | パレット変換は下位 WORD が 15 を超えると自己ループします。 |
| BUG-045 | 第 2 陣営の人数も 15 と 16 の間を往復することがあります。 |
| BUG-046 | オブジェクトの追跡分岐で、中間の MOVE が比較フラグを上書きします。 |
| BUG-047 | 忠誠度の集計で、忠誠度表の BYTE を現在のパケットのオフセットに使います。 |
| BUG-048 | 忠誠度の集計は人数をそのまま除数にするため、ゼロも除算に渡ります。 |
| BUG-049 | 行動予算は武将の C400 属性 BYTE をそのまま使って除算するため、ゼロも除算に渡ります。 |
