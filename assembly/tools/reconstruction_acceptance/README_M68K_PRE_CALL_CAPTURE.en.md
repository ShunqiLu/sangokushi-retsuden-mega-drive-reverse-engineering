# 68000 pre-call input capture

[简体中文](README_M68K_PRE_CALL_CAPTURE.md) · [繁體中文](README_M68K_PRE_CALL_CAPTURE.zh-TW.md) · [日本語](README_M68K_PRE_CALL_CAPTURE.ja.md) · **English**

The tool captures operands, the stack, and available memory before the selected routine body runs. Configuration identifies the entry by call target and machine state layout. Records include the original address and call site.
