# Z80 function entry capture

[简体中文](README_Z80_ENTRY_CAPTURE.md) · [繁體中文](README_Z80_ENTRY_CAPTURE.zh-TW.md) · [日本語](README_Z80_ENTRY_CAPTURE.ja.md) · **English**

The application session manages Z80 entry capture. An explicit audio capture configuration points to the audio entry catalog and records arguments, machine state, and device time. The operator sets its path and limits.
