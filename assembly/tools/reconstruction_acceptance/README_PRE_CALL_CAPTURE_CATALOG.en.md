# Pre-call capture catalog

[简体中文](README_PRE_CALL_CAPTURE_CATALOG.md) · [繁體中文](README_PRE_CALL_CAPTURE_CATALOG.zh-TW.md) · [日本語](README_PRE_CALL_CAPTURE_CATALOG.ja.md) · **English**

The catalog identifies pre-call captures by target address and source entry point. Each entry specifies the target, required fields, and available sources. After loading, pass it to the entry monitor for that session.
