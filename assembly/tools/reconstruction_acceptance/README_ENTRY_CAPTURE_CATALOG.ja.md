# エントリーポイントのカタログ

[简体中文](README_ENTRY_CAPTURE_CATALOG.md) · [繁體中文](README_ENTRY_CAPTURE_CATALOG.zh-TW.md) · **日本語** · [English](README_ENTRY_CAPTURE_CATALOG.en.md)

カタログは呼び出し先を、観測対象の関数、アドレス、入力形式に対応付けます。読み込み時に対象ソースと入口の種類を検証します。ウィンドウ版での有効化は[入口キャプチャー設定](../reconstructed_game/README_ENTRY_CAPTURE.ja.md)を参照してください。
