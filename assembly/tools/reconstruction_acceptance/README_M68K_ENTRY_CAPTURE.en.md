# 68000 entry input capture

[简体中文](README_M68K_ENTRY_CAPTURE.md) · [繁體中文](README_M68K_ENTRY_CAPTURE.zh-TW.md) · [日本語](README_M68K_ENTRY_CAPTURE.ja.md) · **English**

A capture of a selected 68000 routine records registers, the status word, the return slot address, and RAM. It also records the target, origin, and capture location. Multiple entry points can refer to the same read-only capture data.
