# 原版遊戲行為

[简体中文](ORIGINAL_GAME_BUGS.md) · **繁體中文** · [日本語](ORIGINAL_GAME_BUGS.ja.md) · [English](ORIGINAL_GAME_BUGS.en.md)

這些條目說明彙編版保留的操作順序、欄位寬度和分支結果。地址以線性卡匣映象中的 68000 地址表示；暫存器與 RAM 地址在條目中另行說明。條目描述相應條件下的程式行為，實際遊戲中的觸發取決於儲存狀態、場景和指令輸入。

| 編號 | 行為 | 指令地址 | 程式結果 |

| BUG-003 | 鄰接候選刪除後的複製範圍 | `017E14，017E1E` | 複製上界使用遞減後的候選數，部分位置的刪除會留下重複項。 |
