# 原版游戏行为

**简体中文** · [繁體中文](ORIGINAL_GAME_BUGS.zh-TW.md) · [日本語](ORIGINAL_GAME_BUGS.ja.md) · [English](ORIGINAL_GAME_BUGS.en.md)

这些条目说明汇编版保留的操作顺序、字段宽度和分支结果。地址以线性卡带镜像中的 68000 地址表示；寄存器与 RAM 地址在条目中另行说明。条目描述相应条件下的程序行为，实际游戏中的触发取决于保存状态、场景和指令输入。

| 编号 | 行为 | 指令地址 | 程序结果 |
| --- | --- | --- | --- |
| BUG-001 | 粮食运输越限后的数量写入 | `01554A，015552` | 粮食数量增加后按 999,999 比较；超过时将数量设为 99,999。金钱分支的限值为 999,999。 |
| BUG-002 | 一项城市邻接匹配条件恒假 | `016538，01653A，01653E` | 该分支比较原值与减去 16 后的 16 位值，相等条件恒假。 |
| BUG-003 | 邻接候选删除后的复制范围 | `017E14，017E1E` | 复制上界使用递减后的候选数，部分位置的删除会留下重复项。 |
| BUG-004 | AI 寻路返回后的城市表指针 | `034260，034266` | 寻路调用可以在 A1、A2 中留下前沿和网格指针，后续城市扫描沿用这两个寄存器。 |
| BUG-005 | 邻接费用使用网格索引 | `017ECE，017ED8` | 地形和费用读取共用同一个有符号 16 位网格索引，第二次读取提供返回值。 |
| BUG-006 | 到达队伍分离首领的范围 | `01596C，01598E` | 匹配后从下一索引开始复制，末槽之前结束查找。 |
| BUG-007 | 清理势力名单使用递增源指针 | `00E3E2` | 清零地址基于递增后的 A0，指针别名可能把后续终止符写成零。 |
| BUG-008 | AI 装备等级比较包含寄存器高位 | `03372E，033732` | 读取只更新 D5 的低字节，等级判断比较完整 16 位，因此前一高字节影响购买。 |

| BUG-011 | 训练触顶时的进度修正 | `00FD6A–00FD72` | 超过 100 时，进度增量按原增量减去 100 与新值之差计算。 |
| BUG-012 | AI 招兵容量检查使用名单游标 | `033790–0337C6` | 容量比较以递进的名单游标和武将偏移计算地址。 |
| BUG-013 | 第三玩家归属检查使用上次选中值 | `032918` | 比较以先前选中城市寄存器的低字节对照第三玩家槽。 |
| BUG-014 | 寻路前沿耗尽后的分支 | `006544–006554，00664E` | 前沿耗尽后外层循环继续使用原控制路径。 |
| BUG-015 | 两条单向城市邻接 | `0D4BE2–0D4D22` | 这 40 行共有 182 条有向关系，城市 20→33 和 34→36 是单向关系。 |
| BUG-016 | 军队资源决策最终写入动作 13 | `0346B0–0346BE` | 两条条件路径最终写入动作 13，其中一条会先把动作 12 写入同一位置。 |
| BUG-017 | 两处随机样本测试恒为零 | `034620，03510A` | 更新随机种子后，清高位、低字左移和交换的组合使测试用低字恒为零。 |
| BUG-018 | 最大敌军候选的初始强度 | `03498A–0349B0` | 最大强度初值为无符号最大整数，候选强度均走跳过更新的分支。 |
| BUG-019 | 名单强度的低字由成员编号覆盖 | `035092–0350A2` | 每轮读取成员号时覆盖累计寄存器的低字，终止符读取也覆盖这一位置。 |
| BUG-020 | 城市强度扫描使用倒序计数 | `0350B2，0350C2` | 读取目标城市后将同一寄存器置为 255，随后沿用倒序计数值比较。 |
