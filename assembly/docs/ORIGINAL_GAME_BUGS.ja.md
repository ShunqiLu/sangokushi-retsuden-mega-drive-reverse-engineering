# 原作の挙動

[简体中文](ORIGINAL_GAME_BUGS.md) · [繁體中文](ORIGINAL_GAME_BUGS.zh-TW.md) · **日本語** · [English](ORIGINAL_GAME_BUGS.en.md)

アセンブリ版で維持している処理順、フィールド幅、分岐結果を示します。命令アドレスは線形カートリッジイメージの 68000 アドレスで、レジスターと RAM は別に明記します。ゲーム中に発生するかはセーブの状態、シーン、入力した命令によります。

| ID | 挙動 | 命令アドレス | 処理結果 |
| --- | --- | --- | --- |
| BUG-001 | 兵糧輸送の上限超過 | `01554A，015552` | 加算結果を 999,999 と比較し、超えると 99,999 を設定します。金の分岐の上限は 999,999 です。 |
| BUG-002 | 常に偽になる都市隣接判定 | `016538，01653A，01653E` | 元の 16 ビット値と 16 を引いた値を比較するため、一致しません。 |
| BUG-003 | 隣接候補の削除後のコピー範囲 | `017E14，017E1E` | 減算後の件数を上限にするため、削除位置によっては重複が残ります。 |
| BUG-004 | AI 経路探索後の都市テーブルポインター | `034260，034266` | 経路探索後、A1 と A2 に探索前線・グリッドのポインターが残ることがあります。その後の都市走査も同じレジスターを使います。 |
| BUG-005 | 隣接コストのグリッドインデックス | `017ECE，017ED8` | 地形とコストの読み出しに同じ符号付き 16 ビットインデックスを使い、2 回目の読み出し値を返します。 |
| BUG-006 | 到着部隊からの隊長の分離 | `01596C，01598E` | 一致後は次のインデックスからコピーし、最後のスロットの手前で検索を終えます。 |
| BUG-007 | 勢力名簿の整理とインクリメント済みポインター | `00E3E2` | インクリメント後の A0 を基準にゼロを書き込みます。ポインターの別名参照により、後続の終端値を消すことがあります。 |

| BUG-012 | AI 徴兵上限の比較に名簿カーソルを使用 | `033790–0337C6` | 進行中の名簿カーソルと武将オフセットから比較アドレスを計算します。 |
| BUG-013 | 第 3 プレイヤーの所属判定に前の選択値を使用 | `032918` | 以前選択した都市のレジスターの下位バイトを第 3 プレイヤーのスロットと比較します。 |
| BUG-014 | 経路探索前線が空になった後の分岐 | `006544–006554，00664E` | 探索前線を使い切っても、外側ループは元の分岐経路を使い続けます。 |

| BUG-017 | 常にゼロになる乱数判定 2 件 | `034620，03510A` | 乱数シードを更新した後、上位ビットのクリア、下位ワードのシフト、交換を経ると判定対象の下位ワードが常にゼロになります。 |
| BUG-018 | 最強敵軍候補の初期強度 | `03498A–0349B0` | 最大強度の初期値が符号なし整数の最大値なので、どの候補でも更新をスキップします。 |
